# Multi Tenant Entity Tracking And Fraud Detection System

A multi-tenant IoT-based system that combines ESP32-CAM kiosks, BLE proximity tracking, dynamic QR authentication, and Semantic Knowledge Graphs to monitor attendance and physical assets. It uses OWL, RDF, SPARQL, and Graph RAG to detect fraud and anomalies such as proxy attendance, unauthorized access, device tampering, and asset displacement in real time.
